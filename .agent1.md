Build and deploy a personal internship application tracker website called "Midnight Ledger" with the tagline "every application, accounted for."

CORE FEATURES
1. Add / edit / delete an application with these fields: company, role, location, application link, date applied, status, contact person (optional), notes.
2. Status options: Wishlist, Applied, Online Assessment, Interview, Offer, Rejected, Ghosted.
3. Automatically show "X days since applied" on every card, calculated from the date applied and updating daily.
4. If an application has been in "Applied" status for 14+ days with no update, show a subtle "time to follow up" badge.
5. Dashboard at the top with: total applications, active applications, interviews, offers, rejections, and average days waiting.
6. Board view (Kanban columns by status) plus a list view toggle, with search and filter by status.
7. Sort by date applied, company name, or days waiting.
8. Save data in localStorage so it works with no backend, and add Export / Import JSON buttons for backup.

DESIGN (dark and moody)
- Dark by default: deep charcoal-navy background (#0E0F14), slightly lighter card surfaces (#171923), soft off-white text (#E8E6E1).
- Muted accent colors with a gentle glow: ember amber, dusty violet, deep teal, muted rose. Each status gets its own accent color.
- Serif display font for headings (Fraunces, Cormorant Garamond or Playfair Display) and a clean sans for body (Inter or DM Sans), loaded from Google Fonts.
- Atmospheric look: subtle gradients, thin borders, soft glows on hover, light grain texture. Use small moon or clock icons as the only decoration. No flowers.
- Large, elegant numbers on the dashboard, with the "days since applied" counter as the visual highlight on each card.
- Fully responsive and mobile-first, with an optional light mode toggle.
- Moody empty states, such as "Nothing here yet. Log your first application."

TECH
- React + Vite + Tailwind CSS (or plain HTML/CSS/JS if simpler). No backend required.
- Clean, commented, well-organized code.

DEPLOYMENT
- Initialize a git repo and push to GitHub.
- Deploy to Vercel (or Netlify) with the correct build settings (build command: npm run build, output: dist).
- Give me the final live URL and step-by-step instructions to redeploy after changes.
